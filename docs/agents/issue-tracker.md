# Issue Tracker Configuration

## Type
GitHub Issues

## Repository
TheBlueAstronomer/st-stephens-admission

## Workflow
Issues are created and managed using GitHub's built-in issue system.

## Commands used by skills
- `gh issue create` - Create new issues
- `gh issue list` - List existing issues  
- `gh issue edit` - Update issue metadata (labels, assignees, etc.)
- `gh issue view` - View issue details

## Issue URL format
https://github.com/TheBlueAstronomer/st-stephens-admission/issues/{number}
